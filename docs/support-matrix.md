## Unsupported (with rationale)

| Driver | Rationale |
|---|---|
| aio.ThermalZoneDriver | reads host sysfs thermal zones; host-dependent by design |
| gpio.HD44780 | 4/8-bit parallel display timing requires a pin-level protocol decoder; I2C JHD1313M1 and SSD1306 displays are supported |
| gpio.MAX7219/TM1638/AIP1640 | bit-banged shift-register timing requires a pin-level protocol decoder; the generic display buffer remains available |
| i2c./spi.MFRC522 | RFID tag/anticollision state machine not modelled; generic register-map fallback available |
| i2c.Adafruit1109 | two MCP23017 expanders plus keypad scanning not modelled; use the JHD1313M1 display model |
| i2c.BlinkM | ASCII command protocol not modelled; generic register-map fallback available |
| i2c.CCS811 | firmware-mode application start and gas-baseline calibration state machine not modelled; generic register-map fallback available |
| i2c.GrovePi | GrovePi is an ATmega firmware protocol with per-command framing; generic register-map fallback available |
| i2c.PCF8583 | clock/counter calendar semantics are host-time dependent; generic register-map fallback available |
| i2c.Wiichuck | encrypted controller handshake not modelled; generic register-map fallback available |
| i2c.YL40 | capacitive soil-moisture conversion is not characterised by gobot; generic register-map fallback available |

## Generic fallback

Any driver whose chip model is not listed above can still attach to the generic `register-map` chip. It exposes raw registers through the bus console and the UI, but is not claimed as behaviourally supported.
